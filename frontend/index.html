02 / THE FUNDAMENTALS

Three terms. One controller.

PID combines current error, accumulated error, and changing error to calculate a steering correction.

01
P

Proportional

Reacts to the error that exists right now. Increasing the gain makes the controller respond more strongly.

uP = Kp e(t)
02
I

Integral

Accumulates error over time. It can correct persistent offset, but excessive integral action can destabilize a system.

uI = Ki ∫ e(t) dt
03
D

Derivative

Responds to how quickly the error changes. It can help damp sudden changes, though practical systems may need filtering.

uD = Kd de(t)/dt
∑
Controller output

The three terms are combined into a steering command. This website is a numerical demonstration; its behavior is not a guarantee of performance on a physical robot.

u(t) = P(t) + I(t) + D(t)
