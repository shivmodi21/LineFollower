03 / THE FUNDAMENTALS

Three terms. One response.

A PID controller combines three complementary responses to reduce the difference between a target and measured output.

01
P

Proportional

Reacts to the error that exists right now. Increasing gain can make the response faster, but too much can cause overshoot or oscillation.

P(t) = Kc e(t)
02
I

Integral

Accumulates error over time. It can eliminate persistent offset, but aggressive integral action can increase overshoot and slow recovery.

I(t) = (Kc/τI) ∫ e(t) dt
03
D

Derivative

Responds to changes in the measured output. It can add damping and anticipate movement, though real systems often need noise filtering.

D(t) = −Kc τD dPV/dt
Controller output

The terms are combined to calculate the control action. In the process model, the output is constrained between 0 and 100, with integral windup protection at the limits.

u(t) = P(t) + I(t) + D(t)
